# Maira - Personal Voice Assistant

A fully functional Android Voice Assistant with wake word detection, voice recognition, AI brain with memory and context understanding.

## Features

- **Wake Word Detection** - Say "Hey Maira" or "Maira" to activate
- **Voice Recognition (STT)** - Hindi, Hinglish & English support
- **Voice Reply (TTS)** - Natural voice responses
- **Continuous Listening** - Auto resumes after speaking
- **AI Brain** - Smart responses with reasoning
- **Memory** - Remembers conversations, preferences, instructions
- **Context Understanding** - Remembers previous conversation

## Tech Stack
- Kotlin, Android SDK 26+
- SpeechRecognizer (STT)
- TextToSpeech (TTS)
- Room Database for memory
- Foreground Service for background operation
- Coroutines

## Setup
1. Open in Android Studio
2. Sync Gradle
3. Build and install
4. Grant microphone permission
5. Say "Hey Maira" to start
